# NEW FLOW — Estoque

Tela de entrada de estoque do ERP, feita para desktop e celular.

## Fluxo
1. Selecione produtos ou cole uma lista recebida no WhatsApp.
2. Revise itens, quantidade, custo e preços de venda.
3. Confirme a entrada.

A importação entende unidades como `Un`, `Kg`, `Cx`, `Sc`, `Bdj`, `Mç` e `Pct`, além de separar fornecedores e totais.

## Rodar no Cloud Code
É uma aplicação estática. Abra a pasta `new-flow-estoque` e sirva o arquivo `index.html` com qualquer servidor estático.

```bash
npx serve .
```
